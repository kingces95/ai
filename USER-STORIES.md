# User stories

Each entry is the primary user story for one skill and links to its implementation contract.

- [`describe-skill`](describe-skill): As a skill maintainer, I want a flat prompt-first schema with flexible descriptive names, so that AI-generated skill contracts remain simple, discoverable, and composable.
- [`crud-secret`](crud-secret): As a user, I want my AI to maintain an encrypted local password vault and exchange plaintext through the clipboard, so that it can create, recall, update, and delete secrets without exposing them in conversation or on disk.
- [`install-tailscale`](install-tailscale): As a user, I want my AI to install Tailscale with a one-time key, guide administrator approval, and forget the key after connection, so that the machine joins the network without exposing the secret.
