# User stories

Each entry is the primary user story for one skill and links to its implementation contract.

- [`describe-skill`](describe-skill): As a skill maintainer, I want every skill expressed through a compact, consistent contract and indexed by its primary user story, so that I can compose the library and run schema-conformance passes safely.
- [`create-secret`](create-secret): As a user, I want my AI to perform an authorized provisioning flow and create the passwords it needs, so that at the end it can give me those credentials in a format I can import into my password manager.
- [`import-lastpass`](import-lastpass): As a user, I want my staged provisioning credentials converted into LastPass's current import format, so that I can import and verify them without exposing their plaintext in chat or logs.
