# describe-skill

## Prompt

Keep the repository flat, prompt-first, concise, and composable while leaving implementation judgment to the executing AI.

## Synopsis

Defines the shared schema for this repository and the conformance pass used when that schema changes.

## Skills

This is the foundational skill specification and has no dependencies.

## Composition model

Each skill lists direct dependencies. Their acyclic graph defines how small capabilities compose into larger workflows.

## Conformance passes

A schema change updates every affected skill, path, dependency, template, repository index, and primary user story as one coherent change.
